Что такое УПК?

УПК — учебно-производственный комплекс колледжа

ИИ-помощник

Умный, но безопасный

Гибридный ИИ: локальная база отвечает мгновенно офлайн, а для нестандартных вопросов подключается настоящая LLM (Pollinations.AI). Опасные запросы всегда блокируются локально.

  • ✓ Локальная база — работает без интернета
  • ✓ Настоящая LLM для сложных вопросов
  • ✓ Без API-ключей в коде
  • ✓ При неуверенности — честный ответ
